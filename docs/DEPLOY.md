# النشر

خطوات مجرَّبة على Railway، وتنطبق على أي منصة تبني من Dockerfile
(Render، Fly، Koyeb، أو خادم فيه Docker).

## قبل أي شي — وش لازم تعرفه

**القرص في هذي المنصات مؤقت.** أي ملف يكتبه التطبيق يضيع مع أول نشر. يعني
SQLite ما تصلح للإنتاج نهائيًا، ولهذا التطبيق **يرفض الإقلاع** لو لقى نفسه
في وضع إنتاج على SQLite. اربط Postgres من أول يوم.

## الطريق السريع — نشر تجريبي بلا أي متغيّر

لو تبي تشوفه يعمل قبل أي إعداد:

1. Railway → **Deploy from GitHub** → المستودع والفرع.
2. **+ Add Postgres** في نفس المشروع.
3. انشر، ثم **Settings → Networking → Generate Domain**.
4. من تبويب **Console** في الخدمة:
   ```bash
   python -m daif.cli demo --url https://نطاقك
   ```

يطبع لك بيانات الدخول، ويجهّز فندقًا وقاعدة معرفة مفعّلة وثلاث إقامات
وتذاكر — **والبيانات تظهر فوق نموذج الدخول نفسه**، فالزائر يجرّب بلا ما
يسألك عنها.

ولا يحتاج متغيّرًا واحدًا: المنصة تولّد أسرارها وتحفظها، فتصمد أمام إعادة
التشغيل بخلاف المولَّد لعمر العملية.

> **قبل أول استعمال حقيقي:** `python -m daif.cli demo-off` — يطفئ الشريط
> **ويغيّر كلمات المرور المعلَنة**. الإطفاء وحده لا يكفي: كلمة العرض منشورة
> في الكود، ومن يطفئ الشريط ويظن نفسه أغلق الباب أسوأ حالًا ممن تركه ظاهرًا.

الباقي أدناه للنشر الحقيقي.

## ١) جهّز المتغيّرات

ولّد سرّين مختلفين:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"   # مرتين
```

| المتغيّر | لازم؟ | وش يسوي |
|---|---|---|
| `DAIF_ENV` | **نعم** | اكتب `production`. بدونه ما يشتغل فحص ما قبل الإقلاع |
| `DAIF_SECRET_KEY` | **نعم** | يشفّر أسرار الفنادق **ويوقّع أكواد الغرف**. تغييره يُبطل كل الملصقات المطبوعة |
| `DAIF_DASHBOARD_SECRET` | **نعم** | يوقّع جلسات اللوحة. بدونه يخرج كل الموظفين مع كل إعادة تشغيل |
| `DATABASE_URL` | **نعم** | تحقنه المنصة تلقائيًا لما تربط Postgres. الصيغة تُصحَّح داخليًا |
| `ANTHROPIC_API_KEY` | مهم | بدونه **يشتغل النظام** لكن يحوّل كل سؤال لموظف بدل ما يجاوب |
| `WHATSAPP_APP_SECRET` | لو تستخدم واتساب | يتحقق من توقيع الرسائل الواردة |
| `WHATSAPP_VERIFY_TOKEN` | لو تستخدم واتساب | لتأكيد الـwebhook عند Meta |
| `DAIF_BOOTSTRAP_ADMIN_EMAIL` | أول مرة | بريد أول مشغّل للمنصة |
| `DAIF_BOOTSTRAP_ADMIN_PASSWORD` | أول مرة | ١٢ محرفًا فأكثر، وإلا يُتجاهل بصمت |
| `DAIF_MODEL` | لا | الافتراضي `claude-opus-5` |
| `PORT` | لا | تحقنه المنصة |

> **احفظ `DAIF_SECRET_KEY` في مكان آمن.** ضياعه يعني إعادة طباعة ملصقات كل
> الغرف، وفقدان القدرة على فكّ الأسرار المخزَّنة.

## ٢) ارفع

1. من Railway: **New Project → Deploy from GitHub** واختر المستودع والفرع.
2. يقرأ `railway.json` ويبني من `Dockerfile` تلقائيًا.
3. **Add Postgres** من نفس المشروع — يحقن `DATABASE_URL` بنفسه.
4. حطّ بقية المتغيّرات من **Variables**.
5. انشر. `scripts/start.sh` يطبّق الترحيلات ثم يشغّل الخادم.

## ٣) تأكد إنه صحّ

```bash
curl https://<نطاقك>/healthz          # لازم 200
```

وراجع سجلّ النشر: لو فيه نقص في الإعداد بتلقى سطورًا تبدأ بـ `✖` أو `▲`.
`✖` يوقف الإقلاع، و`▲` تنبيه يكمل معه.

## ٤) أول تشغيل

1. **أنشئ أول مشغّل للمنصة.** على منصات النشر ما فيه طرفية عند أول رفع،
   فالطريقة الأسهل متغيّران تضبطهما قبل النشر:

   | المتغيّر | ملاحظة |
   |---|---|
   | `DAIF_BOOTSTRAP_ADMIN_EMAIL` | بريدك |
   | `DAIF_BOOTSTRAP_ADMIN_PASSWORD` | **١٢ محرفًا على الأقل**، وإلا لن يُنشأ الحساب |

   يُنشأ الحساب مرة واحدة فقط: إعادة النشر لا تنشئ حسابًا ثانيًا ولا تُعيد
   ضبط كلمة المرور. بعد أول دخول احذف المتغيّرين.

   ولو كان عندك وصول للطرفية:
   ```bash
   python -m daif.cli create-admin you@example.com --password '<كلمة مرور طويلة>'
   ```
2. أنشئ الفندق الأول من لوحة المنصة.
3. من لوحة الفندق: **الإعدادات** → اختر وضع دخول النزيل.
4. **الإقامات** → **طباعة ملصقات الغرف** → اكتب المدى (`101-320`) → اطبع.
5. **قاعدة المعرفة** → راجع الحقائق وفعّلها. تُنشأ معطّلة عمدًا حتى يراجعها
   مدير قبل ما يتكلم المساعد باسم الفندق.

## عدد النسخ

`numReplicas` واحدة، وهذا مقصود الآن: مُحدِّد المعدّل في الذاكرة، ولو صارت
نسختين صار الحدّ ضعف المقصود. الزيادة تحتاج نقله إلى Redis أولًا.

## تحديث الملصقات

أكواد الغرف مشتقّة من `DAIF_SECRET_KEY` ورقم الغرفة. فإن غيّرت السرّ، **كل
الملصقات القديمة تتوقف** — وهذا مفيد لو تسرّبت، وكارثة لو صار بالغلط.
ولتدوير مقصود بلا كسر: النظام يدعم نسخة ملصق (`version`)، تُزاد وتُعاد
الطباعة تدريجيًا.
